# 🛵 Disk Entregas — Água & Gás

Sistema web para pedidos de **água mineral e gás**, desenvolvido para facilitar as vendas e o recebimento de pedidos pelo WhatsApp.

## 🚀 Funcionalidades

* 💧 Pedido de Água Mineral 20L
* 🔥 Pedido de Gás P13
* ➕ Controle de quantidade
* 📍 Escolha do local de entrega
* 👤 Dados do cliente
* 💳 Forma de pagamento
* 💰 Cálculo automático do total
* 📲 Envio do pedido pelo WhatsApp

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* GitHub Pages

## 📂 Estrutura

```text
Disk-entregas/
```
